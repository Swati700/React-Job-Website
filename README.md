## React Job App

A modern React-based job listing web application where users can browse, add, view, and manage job postings. Built using React, React Router, Tailwind CSS, and React Toastify.

---

## 🚀 Features

* View all job listings
* View single job details
* Add new jobs
* Delete jobs
* Dynamic routing using React Router
* Toast notifications for actions
* Responsive UI with Tailwind CSS
* Loader functions for fetching data
* Clean component-based architecture

---

## 🛠️ Technologies Used

* React
* React Router DOM
* Tailwind CSS
* React Icons
* React Toastify
* Vite
* JSON Server (for mock backend)

## ➡️ Routes

| Route       | Description        |
| ----------- | ------------------ |
| `/`         | Home Page          |
| `/jobs`     | All Job Listings   |
| `/jobs/:id` | Single Job Details |
| `/add-job`  | Add New Job        |
| `*`         | 404 Not Found      |

---

## 📌 Functionalities

### Add Job

Users can add new job listings through a form.

### Delete Job

Users can remove job postings with confirmation.

### Dynamic Routing

React Router is used for navigation between pages.

### Notifications

React Toastify provides success notifications for actions like adding or deleting jobs.
